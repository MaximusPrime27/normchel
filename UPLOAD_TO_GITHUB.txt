КАК ПОЛУЧИТЬ APK

1. Распакуйте этот архив.
2. Откройте репозиторий: https://github.com/MaximusPrime27/normchel
3. Нажмите Add file -> Upload files.
4. Загрузите ВСЁ содержимое папки math_solver_android, включая скрытую папку .github.
5. Нажмите Commit changes.
6. Откройте вкладку Actions -> Build MathSolver APK.
7. После успешной сборки откройте последний запуск.
8. Внизу страницы в разделе Artifacts скачайте MathSolver-APK.
9. Внутри архива будет MathSolver.apk — его можно установить на Android.

ВАЖНО: папка .github должна быть загружена, иначе автоматическая сборка не запустится.
