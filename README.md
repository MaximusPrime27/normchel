# Math Solver Android

Офлайн Android-приложение без Python и сервера.

## Сборка APK в Android Studio
1. Откройте эту папку как проект в Android Studio.
2. Дождитесь Gradle Sync.
3. Выберите **Build → Build App Bundle(s) / APK(s) → Build APK(s)**.
4. APK появится примерно здесь: `app/build/outputs/apk/debug/app-debug.apk`.

Требуется Android SDK 35. Минимальная версия Android: 6.0 (API 23).
